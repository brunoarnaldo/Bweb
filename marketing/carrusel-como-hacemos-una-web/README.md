# Carrusel: cómo hacemos una web

Carrusel de 9 slides (1080 × 1350, formato 4:5) para Instagram, Facebook y LinkedIn. Explica el proceso de Bweb, del primer mensaje a la web online.

| Slide | Qué dice |
| --- | --- |
| 1 | Portada: «Cómo hacemos una web que te trae clientes» |
| 2 | Una web linda no alcanza, tiene que vender, y el camino en 6 pasos |
| 3 | 01 · Nos contás qué necesitás (WhatsApp o formulario) |
| 4 | 02 · Propuesta a medida en 24 horas, sin compromiso |
| 5 | 03 · Diseño y textos, pensada primero para el celular |
| 6 | 04 · Desarrollo: rápida, en todas las pantallas y lista para Google |
| 7 | 05 · Revisás, ajustamos y sale online en días |
| 8 | 06 · Mantenimiento: backups, monitoreo 24/7, errores y cambios incluidos |
| 9 | Cierre: WhatsApp 099 788 934, bweb.uy y @bweb_uy |

## Archivos

- `slide-01.png` … `slide-09.png`: las imágenes, en orden, para subir a Instagram o Facebook.
- `carrusel-como-hacemos-una-web.pdf`: los 9 slides en un PDF, para subir a LinkedIn como documento (así se ve como carrusel).
- `carrusel.html`: el diseño. Los textos se cambian acá.
- `render.cjs`: vuelve a generar los PNG y el PDF desde `carrusel.html` (`npm i -D playwright` y después `node render.cjs`, desde esta carpeta).

Las capturas de los teléfonos salen de `img/proyectos/`. La ferretería de los ejemplos es inventada, no es un cliente.
